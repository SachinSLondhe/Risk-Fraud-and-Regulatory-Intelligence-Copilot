Implement a report generator based only on an existing case and its recorded
evidence.

Use these sections:

REGINTEL COPILOT INVESTIGATION REPORT

1. Report metadata
   - report ID and version
   - case ID
   - generated timestamp
   - generated by
   - review status
   - approved by and approved timestamp, if approved

2. Executive summary

3. Scope of investigation

4. Risk signals
   - rule ID and version
   - observed value
   - configured threshold
   - risk contribution
   - deterministic explanation

5. Transaction and account evidence
   - evidence ID
   - source object
   - source record ID
   - event timestamp
   - evidence hash

6. Policy evidence
   - policy ID and version
   - section and paragraph ID
   - exact retrieved excerpt
   - source filename

7. Analyst finding

8. Known limitations and missing evidence

9. Human review and disposition

10. Audit and lineage metadata
    - source query IDs
    - evidence snapshot timestamp
    - application version
    - report-generation event ID

Requirements:
- Never add evidence that is not attached to the case.
- Never modify an exact policy excerpt.
- Separate deterministic evidence from AI-generated narrative.
- Watermark non-approved reports as DRAFT.
- Prevent viewer roles from approving reports.
- Add a machine-readable JSON representation alongside the human-readable
  report.
- Create a reproducible sample report for one planted synthetic scenario.
